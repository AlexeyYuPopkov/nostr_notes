## ngit

Бинарники `ngit` и `git-remote-nostr` лежат в `~/.local/bin`, формулы в
Homebrew нет. Git находит обработчик `nostr://` по имени файла в `PATH`,
поэтому оба должны лежать в одном каталоге из `PATH`.

```bash
cd ~/Doc/nostr_notes/nostrapps-com

ngit pr list                    # все предложения репозитория
ngit pr view <id>               # детали; --comments покажет тред
ngit pr comment <id>            # написать в тред
ngit pr close <id>              # отозвать своё предложение
ngit account list               # каким ключом подписываем
```

Новая версия предложения: поправить коммит и снова запушить ветку, она
отслеживает `nostr/pr/add-private-notes`. Явная форма —
`ngit send --in-reply-to <id>`.

## REQ через Postman

New → WebSocket Request, адрес `wss://relay.ngit.dev`, Connect, дальше
отправлять строки ниже как сообщения. Реле отдаёт накопленные события, затем
`["EOSE","имя"]`; подписка остаётся открытой, новое приходит само. Закрыть —
`["CLOSE","имя"]`.

Само предложение:

```json
["REQ","pr",{"ids":["b3d84fa6772c43bcb052568c70cb7380d96d10a396f79404daf677d25921e93e"]}]
```

Всё, что на него ссылается: статусы, комментарии, реакции. Главный запрос —
по нему видно, приняли или нет. Пустой ответ значит «ещё не трогали».

```json
["REQ","onpr",{"#e":["b3d84fa6772c43bcb052568c70cb7380d96d10a396f79404daf677d25921e93e"]}]
```

Все предложения к каталогу:

```json
["REQ","prs",{"kinds":[1617,1618],"#a":["30617:3bf0c63fcb93463407af97a5e5ee64fa883d107ef9e558472c4eb9aaaefa459d:nostrapps-com"],"limit":50}]
```

Объявление репозитория — откуда берутся список реле и адреса клонирования:

```json
["REQ","repo",{"kinds":[30617],"authors":["3bf0c63fcb93463407af97a5e5ee64fa883d107ef9e558472c4eb9aaaefa459d"],"#d":["nostrapps-com"]}]
```

Всё, опубликованное вашим ключом:

```json
["REQ","mine",{"authors":["d09c13592a0ac6447259b11266fd7ed1831541856dd492bba03395b48c0f89e0"],"limit":50}]
```

Заметки приложения:

```json
["REQ","notes",{"kinds":[30023],"authors":["d09c13592a0ac6447259b11266fd7ed1831541856dd492bba03395b48c0f89e0"]}]
```

## Git-сервер напрямую

Репозиторий каталога клонируется обычным git по HTTPS, подписи для чтения не
нужны:

```bash
git ls-remote https://relay.ngit.dev/npub180cvv07tjdrrgpa0j7j7tmnyl2yr6yr7l8j4s3evf6u64th6gkwsyjh6w6/nostrapps-com.git
```

Ссылки вида `refs/nostr/<id события>` — это предложения, отражённые на
git-сервере. Источник истины всё равно события на реле, сервер лишь зеркало.
